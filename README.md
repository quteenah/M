# ALI STORE VIP — متجر الخدمات الرقمية

موقع متجر خدمات رقمية متكامل وجاهز للنشر المباشر عبر منصة **GitHub Pages**.

## 🚀 خطوات النشر على GitHub Pages:

1. افتح حسابك على موقع [GitHub](https://github.com).
2. أنشئ مستودعاً جديداً (**New Repository**) وأعطه اسماً مثل `ali-store-vip`.
3. اضغط على **Add file** -> **Create new file** وقم بإنشاء الملفات الأربعة بنفس أسمائها (`index.html` / `style.css` / `app.js` / `README.md`) مع لصق الكود المخصص لكل ملف.
4. اذهب إلى تبويب **Settings** الخااص بالمستودع.
5. اختر من القائمة الجانبية **Pages**.
6. في قسم **Branch** اختر `main` واضغط على **Save**.
7. انتظر دقيقة واحدة وسيظهر لك رابط الموقع المباشر المجاني جاهزاً للمشاركة!
